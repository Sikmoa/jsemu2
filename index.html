For 3DS games that need extra storage to run properly (Persona Q and other DLC/extra-save-data-heavy titles), use this to launch with a freshly created virtual SD card instead of the drop zone above. Once a 3DS game is running, an "SD Card" button in the top-right corner opens a menu showing what's actually on it (files, folders, size used), with a "Create SD Card" action if it's empty or a "Reset SD Card" action if it already holds data, without needing to leave the page.
